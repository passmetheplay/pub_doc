小妙打字通 - 隐私政策

引言

感谢您使用《小妙打字通》。我们非常重视您的隐私，并致力于保护您的个人信息。本隐私政策说明 App 在提供打字练习、购买、配置实验、使用分析和稳定性监控时如何处理数据。

信息收集与使用

1. 必要信息

  • App Store 账号信息：通过 Apple StoreKit 处理应用内购买（会员）和恢复购买，我们不会直接获取您的支付账户信息。
  • 设备与应用信息：可能包括设备型号、操作系统与 App 版本、语言、时区、国家或地区等，用于功能适配、远程配置、分析和故障诊断。
  • 安装标识符：Google Analytics for Firebase 会为每次 App 安装生成随机的 App 实例标识符，用于区分安装实例、统计用户与会话。App 不要求注册账号，也不会将该标识符与姓名、邮箱等直接身份信息关联。

2. 用户生成数据

我们在您的设备本地存储以下信息：

  • 练习记录：您的打字练习历史、速度、准确率等统计数据。
  • 错题本数据：您在练习中输入错误的字符记录和键位错误统计。
  • 偏好设置：如拼音显示、释义显示、震动反馈、外观主题等设置。

3. 分析与诊断数据

  • 使用情况：我们使用 Firebase Analytics 记录 App 启动、页面与按钮交互、练习开始/完成/中途退出、练习类别与模式、速度与准确率、购买页到达及实验分组等事件，用于评估功能效果和改进体验。
  • 内容保护：不会向 Firebase 上传用户输入的练习正文。分析事件可能包含内容长度、类别、统计结果以及用于区分练习内容的摘要标识。
  • 购买事件：Google Analytics 可能记录由 App Store 处理的产品 ID、产品名称、价格、币种和订阅状态等事件；我们不会获得银行卡或 Apple 账号支付凭据。
  • 崩溃与诊断：Firebase Crashlytics 可能收集崩溃日志、堆栈、崩溃时的应用状态、设备与操作系统信息，以及崩溃前的交互面包屑，用于定位问题和提升稳定性。
  • 粗略位置：Firebase/Google Analytics 可能依据网络信息推导国家、地区或城市级别的粗略位置，用于汇总分析和远程配置；App 不请求或收集 GPS 精确位置。

4. 网络访问

  • 会员服务：应用需要访问网络以验证会员购买状态和处理内购交易。
  • 配置与实验：Firebase Remote Config 和 A/B Testing 用于下发功能参数及实验分组。Firebase 可能处理国家代码、语言、时区、系统版本、Firebase App ID、Bundle ID、首次打开时间和实验用户属性。
  • 练习内容：内置练习素材（拼音、词组、文章等）无需联网即可使用；远程配置、分析、购买和故障诊断需要网络。

数据存储与安全

1. 本地存储

  • 为了保护您的隐私，您的练习记录、错题本和统计数据均存储在您的设备本地。
  • 我们不会将您的个人练习数据上传或永久存储在云端服务器中。

2. 云端交互

  • 应用会与 Apple 的 StoreKit 服务，以及 Google Firebase 的 Analytics、Remote Config、A/B Testing 和 Crashlytics 服务交互。
  • 核心练习记录、错题本和偏好设置保存在设备本地；上述第三方服务仅处理本政策列出的购买、配置、分析与诊断数据。

3. 数据安全

  • 本地数据采用 Core Data 标准存储机制。
  • 网络传输全程采用 HTTPS 安全加密协议，确保数据传输安全。

第三方服务

为了提供完整的服务，本应用集成了以下第三方服务：

1. Apple 服务

  • App Store & StoreKit：用于处理应用内购买（会员）及交易安全。

2. Google Firebase

  • Google Analytics for Firebase：用于统计使用情况、功能转化和实验指标。
  • Firebase Remote Config 与 A/B Testing：用于安全下发配置、分配实验变体并评估功能效果。
  • Firebase Crashlytics：用于收集崩溃和诊断信息，定位稳定性问题。
  • Firebase 数据处理受 Google/Firebase 的服务条款和隐私政策约束。

数据保护措施

我们采取以下措施保护您的数据：

  • 最小化数据收集：仅申请应用运行所必须的权限。
  • 本地优先原则：用户的核心练习数据优先存储在本地，不上云。
  • 安全传输：所有网络请求均使用加密通道。
  • 不用于广告追踪：应用不包含广告 SDK，不使用 IDFA，不会为了定向广告或广告衡量而将 App 数据与其他公司的 App、网站或线下数据关联。

用户权限说明

为了提供正常服务，应用可能会请求以下权限：

  • 网络访问：用于购买与恢复购买、远程配置、A/B 实验、使用分析和崩溃诊断。该访问不需要 iOS 弹窗授权。

数据保留和删除

1. 数据保留

  • 您的练习数据和设置保存在设备上，应用卸载前会一直保留。
  • Firebase 数据按照 Google/Firebase 的数据保留设置和适用法律保存。我们只在实现分析、配置与稳定性目的所需的期限内使用这些数据。

2. 数据删除

  • 本地数据：如果您卸载本应用，保存在设备本地的练习记录、错题本及设置将被系统删除且无法恢复。
  • Firebase 数据：App 不提供账号系统，因此没有可供查询的实名账户数据。如需咨询或请求处理与本 App 有关的数据，请通过下方邮箱联系我们。
