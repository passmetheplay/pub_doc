公式快写隐私政策

生效及更新日期：2026 年 8 月 12 日

核心承诺：公式快写不要求注册登录，不包含广告、分析或用户跟踪。图片识别、公式编辑与导出均在您的 iPhone 或 iPad 本地完成，我们不会把图片、公式或使用记录上传到服务器。

1. 我们处理哪些数据

您主动创建的内容

  • 输入或识别得到的 LaTeX 公式、标题、收藏状态和最近删除记录；
  • 尚未保存的编辑草稿；
  • 默认导出场景、图片倍率、背景方式和首次引导状态等偏好。

这些内容只保存在设备本地，用于提供草稿恢复、公式库、收藏、最近删除和导出偏好。

您选择的图片

当您从相册选择或使用相机拍摄公式时，图片只用于本地裁剪和公式识别。识别由应用内置的 Core ML 模型或 Apple Vision 在设备上完成，图片不会上传。

2. 权限用途

  • 相机：仅在您主动选择“拍照识别”时，用于拍摄含有公式的图片。
  • 照片读取：仅在您主动选择“从相册导入”时，用于读取所选图片。
  • 照片添加：仅在您主动选择“保存图片”时，用于把生成的公式图片写入照片。

拒绝这些权限不会影响手动输入、公式预览、公式库和复制 LaTeX 等无需权限的功能。您可以随时在 iOS“设置”中修改授权。

3. 数据收集、共享与跟踪

  • 我们不收集可识别您身份的信息、设备标识符或精确位置；
  • 我们不把任何用户内容出售、出租或共享给第三方；
  • 应用不包含广告 SDK、分析 SDK、崩溃上报 SDK或跨应用跟踪；
  • 应用不创建账号，也不使用云端同步服务。

4. 本地技术组件

公式排版使用应用内置的 KaTeX 资源，数学识别使用应用内置的 UniMERNet Tiny Core ML 模型，并在旧系统上使用 Apple Vision 兼容路径。这些组件均在应用进程或系统框架内本地运行，不会把用户内容发送到外部服务。

5. 访问公开页面

当您主动打开应用内的“完整隐私政策”或“产品介绍”时，应用会从 GitHub Pages 加载相应公开网页。与访问普通网站一样，托管服务可能为安全和运维目的处理必要的网络日志，例如 IP 地址、浏览器类型和访问时间；我们不会把您的公式、图片、收藏或使用记录附加到这些请求中。您也可以选择在系统浏览器中打开页面。相关托管服务的数据处理适用其自身隐私条款。

6. 数据保留与删除

您可以在应用的“我的 → 数据管理”中清空公式历史、最近删除内容或重置设置。卸载应用后，iOS 会删除该应用容器内的数据。已由您主动保存到“照片”或分享给其他应用的文件，需要由您在相应位置另行删除。

7. 儿童隐私

公式快写不会主动收集任何年龄段用户的个人信息。应用面向学习、教学和内容制作场景；儿童应在家长或监护人的指导下管理设备权限。

8. 政策变更

如果应用的数据处理方式发生实质变化，我们会更新本页面和应用内说明，并修改页面顶部日期。涉及新增数据收集时，我们会在适用情况下重新取得您的许可。

9. 联系我们

如果您对本政策或数据处理有疑问，请发送邮件至 bo.xu@163.com。邮件中请注明“公式快写隐私问题”。

本政策适用于 Bundle ID 为 com.weile.tools.formulaflow 的公式快写 iOS / iPadOS 应用。
